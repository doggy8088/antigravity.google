# 產出物
[「產出物」章節](index.html#artifacts)
An **產出物** 是代理為完成任務並向您傳達進度與思路而建立的結構化交付項目。產出物包含豐富的 Markdown 計畫（實作計畫）、程式碼差異、架構圖、圖片與瀏覽器錄影。

隨著代理變得更加自主並在更長時間內執行複雜任務，產出物實現了非同步協作。您無需同步仔細監控每個工具呼叫或步驟；只需在關鍵里程碑審查高層級交付物。

## 跨介面審查產出物
[「跨介面審查產出物」章節](index.html#reviewing-artifacts-across-surfaces)
產出物主要在代理的以下階段產生 **規劃模式** 且可在 Antigravity 應用程式與 Antigravity CLI 兩者中使用。

- Antigravity 應用程式
- Antigravity CLI

### Antigravity 應用程式
[「Antigravity App」章節](index.html#sr-tab-1)
桌面應用程式具備視覺化側邊欄與審查窗格，專為顯示、組織與管理豐富的產出物而最佳化：

- 功能 ：您可以直接在應用程式介面中檢查互動式計畫、審查視覺化程式碼差異，以及播放代理 UI 動作的瀏覽器錄影。

### Antigravity CLI
[「Antigravity CLI」章節](index.html#sr-tab-2)
在輕量終端機介面中，您使用快速的鍵盤驅動審查面板管理產出物：

- 工作流程 ：當代理產生或修改需要您核准的檔案時，通知會出現在終端機狀態列。

## 互動式引導與意見回饋
[「互動式引導與回饋」章節](index.html#interactive-steering-and-feedback)
意見回饋是產出物工作流程的核心機制。根據您的組態，代理會在中間里程碑暫停，並在執行前要求審查其計畫或程式碼編輯：

- 引導代理 ：若產出物（例如實作計畫）與您的目標不一致，您可以在代理修改任何本地檔案前，提供行內文字意見回饋，將代理的思考引導至正確方向。
- 細緻控制 ：此核准循環確保您保持主導地位，讓代理以高度自主運作，同時維持嚴格的人為介入驗證。
