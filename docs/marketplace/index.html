    市集

    「市集」章節

    Marketplace 讓您探索、安裝及管理精選的 Google 與合作夥伴 外掛 以可重複使用的…擴充你的代理 技能, MCP 伺服器, 規則, 生命週期掛鉤，與 子代理。直接跳至 外掛程式目錄 以下內容可直接在 Antigravity App 中開啟任何外掛程式，或複製其 CLI 安裝指令。

    備註

    跨介面同步：安裝於以下項目中的外掛程式 Antigravity 應用程式 會自動更新並顯示於 Antigravity CLI的 已安裝 分頁。

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節

    瀏覽並安裝外掛程式

    「瀏覽並安裝外掛」章節

    開啟 自訂 > Marketplace 直接在 Antigravity App 中執行，或依照下列步驟操作：

    在 Antigravity 中開啟市集瀏覽外掛程式目錄

    如要在 Antigravity App 中手動瀏覽並安裝 Marketplace 外掛程式：

    1. 在左側側欄中，點選 自訂項目 分頁（下方 自動化):

    2. 按一下 市集 分頁以檢視可用的外掛：

    3. 按一下任何外掛程式卡片以檢視其詳細資訊與隨附功能：

    4. 按一下 新增 安裝此外掛程式。您也可以按一下 + 在外掛程式旁邊 的 市集 清單來安裝它，而無須開啟其詳細資訊。

    設定外掛憑證（API 金鑰與 OAuth）

    標題為「Configure plugin credentials (API keys and OAuth)」的章節

    有些外掛程式連線至需要先驗證才能執行其 MCP 工具的外部服務：

    • API 權杖與設定變數: 如果外掛需要 API 金鑰、token 或工作區 URL，在以下位置將它開啟時 自訂項目 > 已安裝 開啟設定對話框，逐一提示輸入每個變數（並附上產生或查詢權杖的直接連結）。
    • OAuth 登入: 如果外掛使用 OAuth 2.0，當該外掛的 MCP 伺服器連線時，Antigravity 會開啟您的瀏覽器以完成登入.

    管理已安裝的外掛

    「管理已安裝的外掛」章節

    若要檢視、切換或解除安裝現有外掛：

    1. 在 自訂項目 面板，按一下 已安裝 分頁：

    2. 按一下 ⋮ 任一已安裝外掛程式旁的選單（或開啟外掛程式卡片），以啟用、停用或設定它。

    3. 選取 解除安裝 從 ⋮ 選單（或在外掛程式詳細資訊頁面）中移除外掛程式。

    您在 Antigravity 應用程式中安裝的任何外掛都會自動同步，並出現在 Antigravity CLI 的 已安裝 分頁。

    使用深層連結開啟外掛程式

    標題為「使用深層連結開啟外掛程式」的章節

    Antigravity App 負責處理 antigravity:// 市集連結，讓您登入後一鍵開啟 目錄或特定外掛程式的詳細資訊頁面：

    • 市集首頁: antigravity://customizations/marketplaces
    • Google 外掛程式: antigravity://plugin/<plugin-name> （或 antigravity://customizations/marketplaces/antigravity-plugins-official/plugins/<plugin-name>)
    • 合作夥伴外掛程式: antigravity://customizations/marketplaces/antigravity-plugins-partners/plugins/<plugin-name> （或 antigravity://plugin/<plugin-name>?marketplace=antigravity-plugins-partners)

    如果連結指定的外掛程式 ID 在目錄中找不到，Antigravity 應用程式 會開啟 市集 瀏覽分頁。如果您發佈外掛程式並想 嵌入 在 Antigravity 中開啟 文件或 README 中的連結，請參閱 分享外掛程式的深層連結.

    在 CLI 中開啟外掛管理員

    「在 CLI 中開啟外掛管理員」章節

    在 Antigravity CLI 中，使用以下方式開啟互動式外掛管理員 /plugin 斜線命令（或其別名 /plugins):

    /plugin
    /plugin—Antigravity CLI
    Plugins
      + Install from local directory... Path: ./my-custom-plugin (press Enter or Esc)
    Keyboard:

    互動式 CLI 外掛管理員——按 Tab（或點選分頁）在「已安裝」與「探索」間切換，↑/↓ 導覽，Enter 展開詳細資訊，空白鍵切換啟用/停用，Ctrl+S 安裝或解除安裝。

    按下 Tab 在…之間切換 已安裝 分頁與 探索 分頁。

    探索分頁

    「探索分頁」章節

    使用 探索 分頁以瀏覽市集目錄並安裝新外掛：

    • 搜尋外掛程式：開始輸入以搜尋並篩選特定外掛程式。
    • 從本機目錄安裝：突顯 從本機 目錄安裝 並按下 Enter 提供本機檔案系統路徑以供外掛安裝。
    • 檢視外掛詳細資訊：突顯外掛程式並按下 Enter 展開其詳細資料檢視。詳細資料檢視會顯示下列資訊：
      • 描述
      • 包含的元件（MCP 伺服器、技能、規則、代理等）
      • 市集名稱
      • 版本
    • 安裝或解除安裝：按下 Ctrl + S 於 未安裝的外掛以安裝，或按下 Ctrl + S 於 已安裝的外掛以解除安裝。

    安裝後

    「安裝後」章節

    外掛安裝後，介面更新如下：

    • 探索分頁：綠色圓點（●）出現在外掛程式名稱旁，表示其安裝狀態。
    • 已安裝分頁：外掛程式名稱出現在 已安裝 分頁清單。

    已安裝分頁

    「已安裝分頁」章節

    使用 已安裝 分頁以檢視與管理你已安裝的外掛：

    • 搜尋已安裝的外掛程式：開始輸入以篩選已安裝的外掛程式。
    • 啟用或停用：按下 Space 在已安裝的外掛程式上，將其 在啟用與停用之間切換。若外掛程式宣告了必要的 MCP 憑證（variables），按下 Space 開啟互動式 提示，在啟用外掛程式前填入這些值。
    • 檢視外掛詳細資訊：按下 Enter 於已安裝的外掛以 展開其詳細檢視。詳細檢視顯示以下資訊：
      • 描述
      • 技能（如適用）
      • MCP 伺服器（如適用）
      • 規則（如適用）
      • 代理（如適用）
      • 市集名稱
      • 本機安裝路徑
      • 版本
    • 解除安裝：按下 Ctrl + S 於已安裝的外掛以 解除安裝。

    鍵盤快速鍵

    「鍵盤快速鍵」章節

    外掛程式管理員中提供下列鍵盤捷徑：

    金鑰Tab動作
    Tab兩者皆是在…之間切換 已安裝 分頁與 探索 分頁。
    Any key兩者皆是在使用中的分頁中搜尋並篩選外掛程式。
    Enter兩者皆是展開外掛詳細資料（或選取 從本機目錄安裝 於 探索).
    Ctrl + S兩者皆是安裝未安裝的外掛，或解除安裝已安裝的外掛。
    Space已安裝切換已安裝外掛的啟用或停用。

    內嵌 /plugin 指令

    「內嵌 /plugin 指令」章節

    除了互動面板， /plugin 支援行內命令以 install, uninstall, enable, disable，與 list 直接從 提示詞安裝外掛，無需開啟外掛管理員 UI：

    • 從市集目錄或本機目錄安裝：指定 <plugin-name>@<marketplace-name> 使用 antigravity-plugins-official 適用於 Google 外掛程式或 antigravity-plugins-partners 適用於合作夥伴外掛程式，或傳入 本機路徑：

      /plugin install firebase@antigravity-plugins-official
/plugin install stripe@antigravity-plugins-partners
/plugin install <local-path>

      例如，執行 /plugin install firebase@antigravity-plugins-official 輸出：

      Successfully installed plugin "firebase" from "antigravity-plugins-official".

    • 內嵌管理與列出外掛：執行以下指令：

      /plugin uninstall <plugin-name>
/plugin enable <plugin-name>
/plugin disable <plugin-name>
/plugin list

    從您的 Shell 安裝（agy plugin)

    「從 Shell 安裝（agy plugin）」章節

    在互動式 TUI 工作階段之外，您可以使用 從 shell 直接安裝與管理外掛 agy plugin:

    • 從市集安裝: 登入之後 agy，從以下位置安裝 Google 外掛程式 antigravity-plugins-official （或傳入裸 <plugin-name>， 預設為 antigravity-plugins-official） 與合作夥伴外掛程式，來自 antigravity-plugins-partners: 
      # Google plugins (bare name defaults to antigravity-plugins-official)
agy plugin install firebase
agy plugin install firebase@antigravity-plugins-official

# Partner plugins
agy plugin install stripe@antigravity-plugins-partners
      執行中 agy plugin install firebase 輸出： 
      Installed plugin "firebase" from antigravity-plugins-official
    • 從 GitHub 連結安裝：直接從 GitHub 儲存庫 URL 複製並暫存外掛程式： 
      agy plugin install https://github.com/<owner>/<repo>
    • 從本機目錄安裝：將本地外掛程式資料夾暫存至您的 設定檔： 
      agy plugin install </path/to/local/plugin>
    • 列出已安裝的外掛：執行 agy plugin list 取得已安裝外掛及其元件數量的 人類可讀摘要，或傳入 --json 輸出包含安裝路徑與元件名稱的 JSON 陣列： 
      agy plugin list
agy plugin list --json
    • 啟用、停用或解除安裝外掛: 
      agy plugin enable <plugin-name>
agy plugin disable <plugin-name>
agy plugin uninstall <plugin-name>

    瀏覽 Marketplace 外掛程式

    篩選精選的 Google (antigravity-plugins-official） 與合作夥伴 （antigravity-plugins-partners） 依發行者、書架或關鍵字篩選外掛程式。按一下 在 Antigravity 中開啟 於任何卡片以開啟其在 Antigravity App 中的詳細資訊頁面（如果尚未安裝應用程式，按鈕會提供直接下載連結）， 或點選 複製 CLI 複製其 agy plugin install 指令。

    使用已安裝的外掛程式

    標題為「Using installed plugins」的章節

    外掛程式安裝並啟用後，其隨附功能會自動在您的工作區中提供：

    元件如何在您的工作流程中使用它
    起始提示詞在 Antigravity 應用程式中 (自訂項目 > 已安裝），開啟外掛程式的詳細檢視並點選任一 建議的提示詞標籤 立即開始引導式任務。
    技能以自然語言要求工作——Antigravity 會透過漸進式揭露按需載入相關的外掛程式技能——或在對話中明確地以下列方式叫用技能： /<skill-name>.
    MCP 伺服器要求代理查詢或操作已連線的服務（例如 Jira、Figma、Datadog、Stripe 或 Firebase）。隨附的 MCP 工具（命名空間為 <plugin-name>_<server-name>）在外掛程式啟用期間自動可用。
    自訂代理 & 子代理主代理會自動將專門任務（例如安全性審查或無障礙稽核）委派給隨附的子代理。您也可以透過 App 中的代理選擇器，直接將外掛程式的自訂代理作為主要工作階段代理來執行， /agents 在 CLI 中，或 agy --agent <agent-name> 從您的終端機（執行 agy agents 列出所有可用的代理）。
    規則 & 掛鉤在外掛程式啟用期間於背景自動執行——強制執行程式設計慣例、SDK 標準，以及工具使用前或使用後的政策檢查，無需手動呼叫。
