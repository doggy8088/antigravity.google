# 代理
[「代理」章節](#agent)
代理是 Google Antigravity 中的主要 AI 功能。它是一個多步驟推理系統，由前沿 LLM 驅動，能推理您現有的程式碼、使用廣泛的工具（包括瀏覽器），並透過工作、產出物等方式與您溝通。

## 核心元件
[「核心元件」章節](#core-components)
代理包含下列核心元件：

- 推理模型
- 工具
- 產出物
- 知識

## 自訂項目
[「自訂項目」章節](#customizations)
您可以使用以下選項自訂代理：

- 代理模式與設定
- MCP
- 規則與工作流程

您可以開始多個代理對話，包括平行進行。透過選取以下項目來刪除代理對話 **右鍵按一下** > **刪除對話** 於代理管理員，或按一下編輯器的代理面板中的垃圾桶圖示。
