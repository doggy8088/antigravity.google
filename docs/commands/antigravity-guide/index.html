    Antigravity 指南指令（/antigravity-guide）

    標題為「Antigravity 指南指令（/antigravity-guide）」的章節

    詢問代理如何使用 Antigravity。 /antigravity-guide 提供代理 官方產品文件，讓它能夠回答有關 Antigravity App、Antigravity CLI、Antigravity IDE 與 Antigravity SDK 的「如何操作…」問題，無需您離開對話。

    總覽

    「總覽」章節

    /antigravity-guide 是 Antigravity App 與 Antigravity CLI 中提供的內建技能。執行指令會為代理提供 每個 Antigravity 介面的快速參考指南，以及官方文件的 網站地圖。 當您詢問如何使用 Antigravity 時，代理也可以自行載入此技能，即使沒有使用斜線指令：

    • Antigravity CLI：側邊欄、對話畫布，以及代理設定與 權限。
    • Antigravity IDE：教導代理可依需求執行或作為斜線指令執行的程序。
    • Antigravity 應用程式：輸入
    • Antigravity SDK：它會列出排程、工作與 權限，並附 Agent 類別、串流回應與工具呼叫，以及互動式聊天 迴圈。

    對於快速參考未涵蓋的問題，例如近期變更或 進階整合，代理會從 擷取相關頁面 antigravity.google/docs 以及來自目前文件的答案。 閱讀文件頁面屬於網頁讀取，因此視您的 權限預設，代理可能會在讀取之前徵求核准 antigravity.google.

    執行 /antigravity-guide

    標題為「執行 /antigravity-guide」的章節

    類型 /antigravity-guide 後方接著您的問題。請像詢問 隊友一樣提問；代理會挑選正確的參考資料，並在有更多內容可讀時連結至文件 頁面：

    /antigravity-guide how do I run the CLI in headless mode in GitHub Actions with a JSON schema?
    /antigravity-guide where do I change the permission preset for this project?
    /antigravity-guide what's the keyboard shortcut for the inline command in the IDE?

    備註

    /antigravity-guide 回答有關使用 Antigravity 的問題。若要讓 代理建立或偵錯自訂項目，例如規則、技能、掛鉤、外掛程式或 MCP 伺服器，請使用 /agy-customizations 或者改用可載入自訂 參考資料的指令。

    後續步驟

    「後續步驟」章節

    探索相關文件：

    • 斜線指令總覽：瀏覽所有可用的 斜線指令。
    • Antigravity CLI 參考：為代理提供持久的指導方針與限制。
    • 設定：將代理連接到外部工具與服務。
    • Antigravity SDK 總覽：擷取螢幕截圖、主控台與網路記錄、效能追蹤、Lighthouse 稽核，以及可選的 WebM 工作階段錄影。
