# 旁問指令（/btw）

「旁問指令（/btw）」章節

使用 `/btw` 提出快速問題，同時讓代理繼續工作。側邊 問題可以讀取檔案並搜尋工作區以查核答案，且 其執行的任何操作都不會新增至您的主要對話。

[Antigravity 應用程式](#tab-panel-169)[Antigravity CLI](#tab-panel-170)Antigravity 應用程式[「Antigravity App」章節](#sr-tab-1)在 Antigravity App 中，/btw 會開啟「旁問」分頁，搜尋程式碼、讀取兩個檔案，並在主要任務持續執行時回答。加速的部分會顯示速度徽章。Antigravity CLI[「Antigravity CLI」章節](#sr-tab-2)在 Antigravity CLI 中，/btw 卡片會在每個工具呼叫執行時顯示，隨後顯示「Called 4 tools」摘要與答案，同時主要任務持續執行。加速的部分會顯示速度徽章。

## 總覽

「總覽」章節

在執行長時間任務時，你經常需要快速查核事實：函式定義的位置、設定使用的值，或代理先前的決定。在主要對話中提問會中斷代理，並增加每個後續回合都需承擔的回合數。旁問可同時避免這兩種情況：

- **了解你的對話**：它會從對話中至今為止所說與所做的一切開始。
- **檢查你的程式碼**：它可以讀取檔案、搜尋你的工作區，以及執行唯讀指令，而非憑記憶回答。
- **與代理並行執行**：你可以在代理回應、執行測試或使用長時間執行的工具時提問。
- **保持你的記錄整潔**：問題、其工具呼叫與答案 不會出現在主要對話中。

## 旁問的運作方式

標題為「旁問的運作方式」的區段

當您傳送 `/btw`，Antigravity 會執行下列動作：

1. **分叉對話**：Antigravity 會建立新的對話， 以你的對話記錄副本作為開頭。主要代理會繼續執行，且分叉中的任何內容都不會寫回主要對話。
2. **要求模型保持唯讀**：系統會告知模型它正在回答旁問。它可以讀取檔案、搜尋程式碼並讀取外部情境，但不會編輯檔案、變更你的工作區或外部狀態、啟動子代理或工作流程，或排程背景任務，除非你明確要求。
3. **保留你的設定**：分叉使用相同的模型， [權限設定](/docs/permissions), [終端機沙箱](/docs/sandbox)、MCP 伺服器，以及管理員政策，與你的主要對話相同。唯讀是對模型的指示，疊加在這些控制之上，而非獨立的沙箱，因此如果你要求旁問進行變更，例如 `/btw fix that typo`，它可以在你的權限範圍內執行。
4. **執行一個代理回合**：模型會呼叫工具，直到完成回答或你將其停止為止。與一般回合一樣，沒有時間限制。

側邊問題因介面而異：

| 行為 | Antigravity 應用程式 | Antigravity CLI |
| --- | --- | --- |
| 答案顯示位置 | A **旁問** 側邊面板中的分頁。 | A `/btw` 提示詞方塊上方的卡片。 |
| 工具呼叫 | 會像對話中一樣，以步驟形式顯示在分頁中。 | 會以即時行顯示在卡片上，然後顯示一行摘要。 |
| 需要核准的工具呼叫 | 核准要求會顯示在分頁中。 | 會自動遭到拒絕，因為卡片無法顯示核准提示。 |
| 後續問題 | 在分頁中傳送更多訊息。 | 不支援。每個 `/btw` 會開始新的分支。 |
| 保留或捨棄 | 將旁問提升為對話，或將其刪除。 | 關閉卡片。答案會保留在該工作階段的卡片記錄中。 |

## 提出旁邊的提問

「提出附帶問題」章節

[Antigravity 應用程式](#tab-panel-165)[Antigravity CLI](#tab-panel-166)Antigravity 應用程式[「Antigravity App」章節](#sr-tab-3)在 Antigravity 應用程式中 (`v2.32.0+`)，每個旁問會以 **旁問** 分頁中的 [側邊面板](/docs/side-panel).  在已傳送至少一則訊息的對話中，輸入 `/btw` 後面接著您的問題，然後按下 Enter: `/btw Where's the retry logic for API calls, and what's the max retry count?` A **旁問** 分頁會以根據您的問題產生的簡短標題開啟。其 第一則訊息會顯示 **開始自** 或 **開始於** 以及側邊問題分支來源的主要對話中的訊息。工具呼叫 （例如搜尋與檔案讀取）會顯示為步驟。側邊問題完成後， 這些步驟會收合為 **適用於** 您可以展開的摘要。   選用：如要提出後續問題，請在分頁底部的編輯器中輸入。 後續問題會繼續該旁問，而非主要對話。  您也可以透過下列方式開始側邊問題： **新分頁**：按一下 **新分頁** (**+**) 在側邊面板中，然後點選 **旁問**。主要對話已有訊息後，即可使用此選項。 **選取的文字**：在對話中選取文字，然後點選 **詢問 /btw** 將其引用至新的側邊問題。 若要停止執行中的側邊問題，請按一下 **停止側邊問題** 在分頁標頭中。 如果工具呼叫需要您的核准，要求會顯示在分頁中，與對話中相同。Antigravity CLI[「Antigravity CLI」章節](#sr-tab-4)在 Antigravity CLI 中（`v1.5.0+`)，輸入 `/btw` 後面接著您在提示詞方塊中的 問題。如果您尚未開始對話，CLI 會建立一個對話：`/btw Which port and timeouts does server.go configure? Read the file to check.`A `/btw` 卡片會在主要對話繼續進行時於提示詞方塊上方開啟。 卡片會顯示每個執行中的工具呼叫（`✓` 完成， `⋯` 執行中， `✗` 失敗）。 答案就緒後，工具呼叫會收合為摘要行，例如 `Called 4 tools (3 read_file, 1 run_command)`.請注意下列事項： **每張卡片一個問題**：每個 `/btw` 會開始主要對話的全新 分支，且看不到先前的側邊問題。 **一次一個**：如果你在第一個旁問完成前又提出另一個旁問，CLI 會請你稍候或按下 Esc 取消執行中的 項目。 **無核准提示**：需要你核准的工具呼叫，例如 尚未允許的 Shell 指令，會遭到拒絕。如果旁問仍在等待核准，它會停止並請你改在 主要對話中提問。 **僅限互動式工作階段**: `/btw` 於無頭模式不可用 (`-p` 或 `--print`）或在 [遠端代理](/docs/remote-agents) 工作階段。

## 管理旁問

標題為「管理旁問」的區段

在 Antigravity App 中，旁問會與對話一起儲存，直到你將其刪除為止。在 Antigravity CLI 中， `/btw` 答案會保留在目前的 工作階段中。

[Antigravity 應用程式](#tab-panel-167)[Antigravity CLI](#tab-panel-168)Antigravity 應用程式[「Antigravity App」章節](#sr-tab-5)重新開啟或重新命名旁問[標題為「重新開啟或重新命名旁問」的區段](#reopen-or-rename-a-side-question)關閉 **旁問** 分頁不會刪除側邊問題。若要重新開啟， 請執行下列任一操作： 在 [**總覽** 面板](/docs/side-panel#the-overview-panel)，點選 **側邊問題** 區段。 按一下 **新分頁** (**+**) 在側邊面板中搜尋該旁問。 符合的結果會顯示在 **側邊問題**. 若要重新命名側邊問題，請在分頁標頭中按兩下其名稱，輸入新名稱， 然後按下 Enter.提升或刪除旁問[標題為「提升或刪除旁問」的區段](#promote-or-delete-a-side-question)若要將側邊問題轉換為完整對話，請等待其完成， 然後按一下 **提升為對話** 在分頁標頭中。如果系統詢問您要在何處 建立對話（例如目前的資料夾或新的工作樹）， 請選擇其中一個。Antigravity 會開啟新對話並關閉側邊問題 分頁。您無法將仍在執行中的側邊問題，或在子代理對話中提出的側邊問題，升級為對話。若要永久刪除側邊問題，請按一下 **刪除旁問** 在分頁 標頭中，然後按一下 **刪除** 以確認。此操作無法復原。Antigravity CLI[「Antigravity CLI」章節](#sr-tab-6)重新開啟先前的 `/btw` 答案[「重新開啟先前的 /btw 回應」章節](#reopen-previous-btw-answers)若要重新開啟最新的 `/btw` 在不提出新問題的情況下顯示卡片，執行 `/btw` 不帶引數：`/btw`卡片導覽控制項[「卡片導覽控制」章節](#card-navigation-controls)當 `/btw` 在 CLI 中可見卡片時，使用以下快速鍵： 金鑰動作Tab展開截斷的答案或收合展開的卡片。↑ / ↓當答案超過檢視區高度時，在展開的卡片內以一行向上或向下捲動。否則，這些按鍵保留其一般的提示詞記錄行為。PgUp / PgDn在展開的卡片內以一頁向上或向下捲動。← / →循環切換上一個與下一個 `/btw` 目前工作階段中的回應。Esc關閉 `/btw` 卡片，或取消仍在執行中的側邊問題。Enter關閉 `/btw` 卡片，或在提示詞方塊為空時取消執行中的側邊問題。如果您已輸入提示詞， Enter 照常提交。複製 `/btw` 回應複製到剪貼簿[「將 /btw 回應複製到剪貼簿」章節](#copy-a-btw-response-to-the-clipboard)若要複製最新 `/btw` 答案，而非主要代理的上一個回應， 請執行：`/copy btw`CLI 會複製畫面上答案的完整 Markdown，若您已關閉卡片，則複製最新 答案的完整 Markdown，即使卡片已收合或 捲動亦然。
