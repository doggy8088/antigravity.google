# 任務群組
[「工作群組」章節](#task-groups)
當代理處於規劃模式時，它會以任務群組處理大型複雜任務，將問題拆解為更小、更易處理的工作單元。代理通常會同時處理較大任務的多個部分，而任務區段會向您呈現這些變更。下列區段描述一個任務群組範例。

## 總覽
[「總覽」章節](#overview)
任務群組的頂部元件會指定該任務的總體目標，並彙整此工作單元內所做的變更。「已編輯檔案」區段讓您快速稽核變更：點選檔案藥丸即可查看變更檔案的目前狀態。

## 子任務與進度更新
[「子工作與進度更新」章節](#subtasks-and-progress-updates)
在任務群組中，代理會識別將必要變更模組化的子任務，您可以在這些進度更新區段中查看代理完成的所有工作。預設情況下，每個子任務的詳細資訊會收合，您可以使用切換按鈕展開代理採取的確切步驟。

## 待處理步驟
[「待處理步驟」章節](#pending-steps)
有時，進度更新會包含待處理步驟，例如需要核准的瀏覽器設定或終端機指令。代理不會要求您展開所有更新，而是在任務群組末端提供專屬區段，讓您檢視這些待處理步驟。
