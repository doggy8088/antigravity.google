# 視窗標題指令（/title）
[「視窗標題指令（/title）」章節](#window-title-command-title)
以互動方式設定動態終端機視窗標題。

## 總覽
[「總覽」章節](#overview)
The `/title` 指令可讓您切換終端機視窗標題功能的開關，或明確設定其狀態。啟用後，終端機標題列會動態更新，顯示啟用中的模型、工作區與代理狀態。

關於如何撰寫自訂指令碼以格式化視窗標題的詳細資訊，請參閱概念性 **終端機標題自訂指南**.

## 互動式切換
[「互動式切換」章節](#interactive-toggling)
您可以透過執行以下指令來控制視窗標題功能 `/title` 指令。

若要開啟或關閉此功能，請執行下列指令：

```
/title
```

若要明確啟用，請執行下列指令：

```
/title on
```

若要明確停用，請執行下列指令：

```
/title off
```
