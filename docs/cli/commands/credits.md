# AI 點數指令 (/credits)
[「AI 額度指令（/credits）」章節](#ai-credits-command-credits)
以互動方式檢視及管理您的 AI Premium 點數。

## 總覽
[「總覽」章節](#overview)
The `/credits` 指令會在 TUI 中開啟專屬面板，顯示您目前的 AI Premium 點數餘額、消耗記錄，以及管理訂閱或購買額外點數的連結。

關於點數追蹤方式、低點數警示與設定組態的詳細資訊，請參閱概念性 **AI 點數指南**.

## 使用 credits 指令
[「使用額度指令」章節](#using-the-credits-command)
若要檢視點數狀態，請依照下列步驟操作：

1. 類型 /credits 於提示詞方塊。
2. 按下 Enter .

```
/credits
```

點數面板顯示下列詳細資訊：

- 可用餘額 ：您剩餘的 AI Premium 點數。
- 用量摘要 ：本計費週期已消耗點數的明細。
- 快速連結 ：購買更多點數或升級方案的動作（會開啟相關的網頁入口）。

按下 `Esc` 關閉面板並返回主提示詞。
