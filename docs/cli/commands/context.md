# 情境指令（/context）
[「上下文指令（/context）」章節](#context-command-context)
檢查作用中對話的 Token 消耗與情境視窗使用量。

## 總覽
[「總覽」章節](#overview)
The `/context` 指令會開啟互動式 **情境用量** 面板，於 Antigravity CLI。顯示模型總 上下文視窗的比例視覺網格，以及各類別字符明細、壓縮 檢查點與追蹤的工作區檔案。

## 開啟內容用量面板
[「開啟上下文使用量面板」章節](#open-the-context-usage-panel)
若要檢視目前的內容視窗使用量，請執行下列指令：

```
/context
```

## 了解內容細目
[「了解上下文明細」章節](#understand-the-context-breakdown)
在寬終端機上， **情境用量** 面板於左側渲染比例儲存格網格 ，右側為字符摘要。較窄的終端機上，摘要 堆疊於網格上方，讓每個指標都可讀。

### 視覺格線指示器
[「視覺格線指示器」章節](#visual-grid-indicators)
網格中的每個儲存格代表作用中模型的情境視窗上限的比例份額：

- `◉` （已填儲存格） ：代表目前使用中的 Token，依 類別以顏色區分（系統指示、使用者訊息、代理回應、工具呼叫與 載入的自訂項目）。
- `□` （未填儲存格） ：代表模型 上下文視窗中的剩餘可用容量。

### 權杖使用量類別
[「符記用量類別」章節](#token-usage-categories)
摘要面板會將您的權杖用量拆解為下列列。 **使用者訊息**, **代理回應**，與 **工具呼叫** 列一律顯示；其餘列僅在該類別正在消耗 token 時出現。每列開頭都有一個標記： `◉` 適用於對話列， `⛁` 適用於 系統提示詞、系統工具、系統額外負擔與自訂列， `□` 釋出 可用空間，以及 `⊠` 適用於檢查點緩衝區。

- 使用者訊息 ：來自您的提示詞與內嵌附件的權杖。
- 代理回應 ：模型回覆與推理步驟所產生的權杖。
- 工具呼叫 ：工具引數與指令輸出所耗用的權杖。
- 系統提示詞 , 系統工具 ，與 系統額外負擔 ：內建系統指令、內建工具定義及其他系統層級開銷所使用的權杖。
- 規則 , 技能 , 子代理 , 工作流程 ，與 外掛程式 ：各類已載入的自訂項目所使用的權杖。
- MCP 工具 ：已連線 MCP 伺服器的工具結構描述所使用的權杖。
- 系統訊息 ：來自對話中系統產生訊息的權杖。
- 可用空間 ：達到模型上下文 上限前的剩餘 Token 容量。
- 檢查點緩衝區 ：檢查點摘要所持有的權杖，用以代表已壓縮的較舊對話回合。此面板會將其獨立追蹤，排除在表格之外，因此摘要後的歷史紀錄不會膨脹實際使用百分比。

### 檢查點與追蹤的檔案
[「檢查點與追蹤檔案」章節](#checkpoints-and-tracked-files)
在摘要網格下方， `/context` 面板列出作用中的工作階段狀態：

- 檢查點 ：顯示作用中的上下文內檢查點，以及已摘要的 歷史檢查點計數。使用 /rewind 回復到較早的檢查點。
- 已追蹤的檔案區段 ：列出已載入的 知識檔案 , 產出物 檔案 ，與 技能檔案 附上各自的 token 計數，後接自動偵測的 系統檔案 （例如 ~/.gemini/GEMINI.md 或 .agents/rules/ ），僅依路徑列出。每個區段標頭會顯示 相關提示（ /rules , /artifact , /skill ）；對應的可執行 指令為 /rules , /artifact ，與 /skills .

### 導覽控制項
[「導覽控制」章節](#navigation-controls)
在下列項目中使用下列鍵盤快捷鍵 **情境用量** 面板：

| 金鑰 | 動作 |
| --- | --- |
| ↑ / ↓ （或 k / j ) | 以一行向上或向下捲動。 |
| PgUp / PgDn | 以一頁向上或向下捲動。 |
| Ctrl + U / Ctrl + D | 以半頁為單位向上或向下捲動。 |
| g / Shift + G | 跳至面板的頂部或底部。 |
| Esc | 關閉面板並返回提示詞。 |

## 管理內容增長
[「管理上下文增長」章節](#manage-context-growth)
隨著對話增長，Antigravity 會自動將較舊的回合壓縮為檢查點摘要，讓您的工作階段能持續進行而不觸及模型的權杖上限。 **檢查點** 面板區段顯示此情況已發生多少次。

為在長時間工作階段中維持內容視窗輕量且反應迅速，請考慮以下做法：

- 搭配以下項目提出旁邊的提問 `/btw` ：使用 `/btw` 供 快速的旁枝問題使用，讓問題與答案不會加入您的 主要對話紀錄。
- 在不相關的任務之間重設 ：執行 /clear （別名 /new ）於切換 至不需要先前對話內容的新任務時。
- 分支出對話 ：執行 /fork （別名 /branch ）或 /rewind 從較早的檢查點探索替代方案。
- 停用未使用的 MCP 伺服器 ：若 MCP tools 佔用大量情境視窗，請開啟 /mcp 停用目前專案不需要的伺服器。
