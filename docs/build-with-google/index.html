    與 Google 攜手建置

    「與 Google 共同建構」章節

    Antigravity App 讓使用熱門 Google 技術堆疊建置變得無縫。我們與 Google 各團隊合作，建立了精選的原語套件組合，包括針對特定生態系統預先設定的技能、MCP 伺服器與編輯器擴充功能。

    無須個別搜尋工具，即可啟用這些套件，立即賦予代理對 Google 平台的深入知識。

    如何啟用

    「如何啟用」章節

    您可以在兩個時機點啟用 Build with Google 整合：

    • 入門期間：選取您計畫使用的堆疊的核取方塊。
    • 在設定中：導覽至 設定 > 自訂項目 > Google 外掛程式建置 隨時新增或移除整合。

    主要功能

    雲端 & 資料

    Firebase 套件

    將您的 AI 程式撰寫代理轉變為專門的 Firebase 專家，可撰寫程式碼、設定 Firebase Security Rules，並管理即時資源。

    包含內容

    • 涵蓋核心 Firebase 服務（包括 Firestore、Authentication、App Hosting 等）的代理技能套件。

    主要功能

    • 採取行動： 不只撰寫程式碼。你的代理可以初始化服務、管理驗證使用者、部署新的 Firebase 安全規則，並直接處理你的 Cloud Firestore 資料。
    • 隨時掌握最新動態： 使用官方的版本感知提示詞，引導代理完成設定任務。
    • 提高準確度： 存取您的專案'的環境與結構描述，以提供更相關且準確的協助。
    探索 Firebase 代理技能指南
    AI & 科學

    Google Antigravity SDK

    使用 Antigravity Python SDK 建構自主 AI 代理。

    包含內容

    • 包含 Antigravity Python SDK (google-antigravity) 架構參考、入門範例與設定指南的代理技能。

    主要功能

    • 建置代理： 您的代理可以使用 SDK 最佳實務，搭建新的 Antigravity 代理、設定模型、註冊自訂 Python 工具，以及連接 MCP 伺服器。
    • 注意安全： 使用官方指引實作宣告式安全政策，包括預設拒絕範本與引數層級述詞。
    • 深入了解： 存取生命週期掛鉤、多代理委派、結構化輸出、多模態輸入與權杖用量可觀測性的參考資料。

    Dart 與 Flutter

    用於從單一程式碼庫建置行動、網頁、桌面與嵌入式裝置原生編譯應用程式的官方 Dart 與 Flutter 外掛程式。

    包含內容

    • 適用於常用 Dart 與 Flutter 工作流程的代理技能套件，外加用於與開發環境及執行中的 Dart 或 Flutter 應用程式互動的 Dart MCP 伺服器。

    主要功能

    • 提升開發人員體驗： 運用靜態分析工具、透過 pub 的套件管理常式、程式碼格式化，以及自動化程式碼重新命名功能。
    • 多平台開發： 使用單一程式碼基底，為行動裝置、網路與桌面打造高品質應用程式。
    • 提高準確度： 為代理提供結構化指令，以完成常見的開發者任務，例如建構自適應版面配置。

    雲端 & 資料

    Data Agent Kit 入門套件

    專為在 Google Cloud 上建置端對端分析、ETL 與 AI 工作流程的資料工程師與資料庫從業人員，提供的專門技能與 MCP 工具套件。

    包含內容

    • BigQuery SQL 的精選領域技能 & ML、dbt 轉換、Apache Spark、Dataflow、Cloud Spanner、BigLake Iceberg 目錄，以及工作流程協調。
    • 整合 Google Cloud 資料 MCP 伺服器，用於資料庫檢查、查詢執行與管線疑難排解。
    • 筆記本、儀表板 (Streamlit) 與語意建模指引。

    主要功能

    • 端對端 medallion 管線： 以自然語言提示您的代理，從 Cloud Storage 擷取原始資料，透過 dbt 或 Spark 在青銅、白銀、黃金三層之間轉換，並透過 BigQuery 或 Spanner 提供服務。
    • SQL & ML 程式碼產生： 撰寫最佳化的 BigQuery SQL、訓練 BigQuery ML 模型（XGBoost、K-Means），或建置互動式 LookML 與 Streamlit 資料應用程式。
    • 管線協調 & 除錯： 自動搭建跨 Google Cloud 資料生態系統的編排工作流程，並偵錯失敗的 Dataflow 或 Dataproc 工作。
    行動裝置 & 地圖

    Google Maps Platform

    為您的 AI 程式設計代理配備 Google Maps Platform 知識與工作流程，在 Web、Android、iOS 與網頁服務上設計、建置並部署具備位置感知功能的特性。

    包含內容

    • 涵蓋核心 Google Maps Platform API 與 SDK 的代理技能套件，包括 Maps（2D/3D、Street View、Static、Styling、Clustering）、Places、Address Validation、Geocoding、Routes & ETA（包含環保路徑規劃）、地理圍欄、熱圖，以及環境 API（空氣品質、花粉、日照、天氣）。

    主要功能

    • 建置豐富的地點體驗： 為行動裝置、網站與後端服務，撰寫可用於互動式地圖、地點查詢、路線最佳化、地理圍欄與環境洞察的正式環境程式碼。
    • 低摩擦原型製作： 使用 Maps 展示金鑰開始使用，無需立即設定帳單，並在轉入正式環境時引導你建立帳戶並限制 API 金鑰。
    探索 Google Maps Platform 代理技能儲存庫
    雲端 & 資料

    Google Cloud 開發者

    為您的 AI 程式設計代理配備 Google Cloud 知識與工作流程，直接在 Antigravity 中設計、建置、部署與管理可擴充的雲端基礎架構與服務。

    包含內容

    • 涵蓋核心 Google Cloud 服務、架構設計與部署工作流程的代理技能套件，包括運算（Cloud Run、GKE、Compute Engine）、無伺服器 & 事件（Cloud Functions、Eventarc、Pub/Sub）、儲存空間 & 資料庫（Cloud Storage、Cloud SQL、Firestore、Spanner、AlloyDB）、AI & 資料（Gemini 平台、BigQuery）、身分識別 & 安全性（IAM、Secret Manager）與基礎架構即程式碼（Terraform、gcloud CLI）。

    主要功能

    • 建置並部署雲端原生應用程式： 讓您的代理能撰寫生產級服務架構、容器定義、IaC 組態與用戶端程式庫整合，涵蓋多種執行期（Node.js、Python、Go、Java）。
    • 引導式設定 & 基礎架構管理： 使用最佳實務範本與自動化 gcloud 工作流程，簡化專案佈建、服務啟用、IAM 授權與資源設定。
    • 智慧疑難排解 & 可觀察性： 診斷部署錯誤、檢查 Cloud Logging 與 Cloud Monitoring 遙測資料，並針對成本、安全性與效能最佳化組態。
    探索 Google Cloud 代理技能儲存庫

    正在搜尋 Google 開發人員文件？

    組合包讓你的代理具備特定技術堆疊的能力。若要讓它針對任何 Google 開發人員產品的回答以最新文件為依據，請將其與 Google Developer Knowledge MCP 伺服器，從 MCP Store 一鍵安裝，使用您的 Google 憑證。它讓代理能搜尋並閱讀 Android、Firebase、Google Cloud、Google Maps Platform、Antigravity 及其他 Google 開發人員產品的官方文件。如需詳情與範例提示詞，請參閱 搜尋 Google 開發人員文件 在 MCP 指南中。
