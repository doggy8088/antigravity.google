# 與 Google 攜手建置

「與 Google 共同建構」章節

Antigravity App 與 Antigravity CLI 讓您能輕鬆使用熱門的 Google 技術堆疊進行建置。我們已與 Google 各團隊合作，打造精選外掛程式，內含針對特定生態系統預先設定的技能、MCP 伺服器、規則與自訂代理。

您無須逐一搜尋個別工具，可以直接在 Antigravity 應用程式中開啟下方的任何外掛程式，或從終端機以一個指令安裝。

## 如何啟用

「如何啟用」章節

您可以從以下位置安裝及管理 Build with Google 外掛程式 [市集](/docs/marketplace) 橫跨 Antigravity App 與 Antigravity CLI：

- **直接深層連結**：按一下 **在 Antigravity 中開啟** 於下方的任何套裝卡片，直接跳至其在 Antigravity App 中的詳細資訊頁面，或點選隨附的 CLI 按鈕以複製其 `agy plugin install` 指令。
- **瀏覽並安裝**：按一下 **自訂項目** 在左側邊欄中開啟 **市集** 分頁，並瀏覽 **與 Google 攜手建置** 書架（或執行 `/plugin` 於 Antigravity CLI 中）。
- **管理已安裝的外掛**: 開啟 **自訂項目** > **已安裝** 隨時啟用、停用、設定或解除安裝外掛程式。
