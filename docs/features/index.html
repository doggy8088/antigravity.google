    Antigravity 功能

    標題為「Antigravity features」的章節

    Antigravity App 與 Antigravity CLI 執行的是同一個代理，因此大多數功能在兩者上都能使用。本頁先介紹兩者共用的功能，再介紹專屬於下列介面的功能： Antigravity 應用程式 和 Antigravity CLI.

    應用程式和 CLI 中的功能

    標題為「Features in the App and CLI」的章節

    當某項功能在 App 與 CLI 中的運作方式不同時，請在分頁中選取您的介面。您的選擇會套用到本頁的所有分頁，並在整個文件中記住。

    專案

    「專案」章節

    代理在以下環境中運作： 專案, 定義代理可存取的資料夾，以及其使用的設定與權限.

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節
    • Worktree 支援：專案原生支援 Git worktree，讓代理可在隔離的背景資料夾中運作。
    • 範圍化設定: 設定具有範圍，您可以為每個專案設定不同的安全性設定。也就是說，受信任的專案可以採用較寬鬆的設定，不受信任的資料夾則可採用較嚴格的安全性設定。關於可用的預設，請參閱 權限預設集.
    • 範圍化權限: 將權限授予附加到專案，以控制代理可存取的範圍。在對話中手動授予的權限可以保留，讓代理隨著時間學習受信任的動作.
    • 多資料夾存取：您可以設定專案在多個資料夾中工作，讓代理在同一對話中跨不同程式碼庫運作。

    Antigravity CLI

    「Antigravity CLI」章節
    • 預設專案: 對話會在以下環境中執行 default-cli-project 除非您使用以下參數啟動 CLI --project=<project_id> 或 --new-project.
    • 已繼續的對話: 當您以以下方式繼續對話時： /resume 或 --conversation, CLI 會使用該對話的專案.
    • 分岔對話：執行 /fork <project_id> 在另一個專案中繼續目前對話的副本。

    深入了解專案.

    預設安全

    「預設安全」章節

    依預設，代理在執行敏感操作前會先詢問，並將檔案存取範圍限制在你的專案資料夾內。詳細內容因介面而異：

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節
    • 互動式核准：依預設，指令會在隔離的 終端機沙箱 無須提示，代理在沙箱外執行終端機命令之前會請求您的明確許可。在以下位置之下： 自動 預設值，沙箱外的命令會自動接受評估，讓安全、可還原的命令繼續執行，而具風險或不可還原的動作則會請求您的核准。搭配 先前的權限設定，代理在執行任何終端機指令前都會先詢問。
    • 有界存取: 預設情況下，您的代理只能在專案所提供的資料夾內讀取與寫入。如果您放寬權限設定（例如選擇 Turbo 預設）下，代理可讀寫您整台電腦。

    Antigravity CLI

    「Antigravity CLI」章節
    • 互動式核准: 預設 request-review 權限會在代理寫入檔案、執行 Shell 命令或使用網頁工具之前先詢問，除非其中一條允許規則符合。在 auto 模式，CLI 會核准工作區檔案編輯，在 終端機沙箱，並評估沙箱外的指令，因此只有具風險或不可逆的動作會徵求您的核准。
    • 終端機沙箱：The 終端機沙箱 預設為關閉。使用以下方式開啟： enableTerminalSandbox 於 settings.json 或 --sandbox 旗標。 auto 模式會自動將其開啟。
    • 工作區之外的檔案: 代理在讀取或編輯工作區資料夾外的檔案前會先詢問。若要將這些檔案視為工作區檔案，請開啟 allowNonWorkspaceAccess.

    深入了解權限 和 終端機沙箱.

    Orchestrator

    標題為「Orchestrator」的章節

    選取 Orchestrator 在模型選取器中（或使用 /model 在 CLI 中）即可用更快的週轉速度和更少的權杖用量，獲得較大規劃器模型的品質。規劃器會探索程式碼庫、規劃工作並檢視進度，而較快的執行器模型（例如 Gemini 4 Hydrogen）則負責執行搜尋、編輯、建置與測試，並在計畫需要修正時將控制權交還給規劃器。在 Google AI Ultra 和 Google AI Pro 中，你可以自訂預設 協調器模型 和 執行器模型 在 Antigravity App 中的 設定 > 模型 > Orchestrator 設定 或從以下位置為單一對話選取規劃器 Orchestrator 子選單，並逐步執行 Planner 以下項目上的列 Orchestrator 列，位於 /model 在 CLI 中；在 Gemini Enterprise 中，Orchestrator 僅執行 Gemini 4 Carbon 搭配 Gemini 4 Hydrogen（不提供自訂角色選擇）。Orchestrator 適用於 Google AI Ultra、Google AI Pro（付費方案，或符合資格高階裝置的試用），以及 Gemini 企業版.

    深入了解 Orchestrator.

    子代理

    標題為「Subagents」的章節

    主代理可以將研究、建置或測試執行等工作委派給子代理。每個子代理都以全新的脈絡開始，在自己的對話中執行，與您的主對話平行進行。

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節

    在側邊面板的 總覽, 開啟 子代理 並選取一個子代理以追蹤其對話。

    Antigravity CLI

    「Antigravity CLI」章節
    • 監控與核准：開啟 /agents 面板，以監控子代理並核准其要求。
    • 前往核准：按下 Alt + J 跳至下一個等待核准的子代理。
    • 就地核准：按下 Ctrl + K 核准待處理的要求，無需離開主要對話。

    深入了解子代理.

    動態工作流程

    標題為「Dynamic Workflows」的章節

    執行 /run-workflow <task> 讓代理撰寫一個簡短的 Python 指令碼，協調多個代理，例如每個變更檔案一位審查者，或測試後修正的管線。你核准該指令碼、即時追蹤其階段與代理，並可儲存指令碼以便日後再次執行。

    深入了解動態工作流程.

    瀏覽器子代理

    標題為「Browser subagent」的章節

    讓 browser 子代理會開啟頁面、點擊操作流程、檢查主控台與網路錯誤、擷取螢幕截圖，並在完成工作前驗證視覺修正：

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節
    • 內建瀏覽器自動化 (v2.30.0+，個人 Google 帳號)：以自然語言詢問或執行 /browser 以直接在內建瀏覽器內啟動瀏覽器子代理——無須安裝或設定 Chrome。
    • 平行分頁與即時交接：將瀏覽器螢幕截圖儲存為產出物，並 為代理留下區域註解。 browser 子代理會同時在隔離分頁中執行，具備動畫即時游標、零焦點搶奪，以及一鍵 停止 接管按鈕，以及暫停與恢復登入交接。
    • 商務版與企業版帳戶上的 Chrome DevTools：執行 /browser 以驅動您本機的 Google Chrome（v144+) 透過 Chrome DevTools MCP。

    Antigravity CLI

    「Antigravity CLI」章節
    • 可依需求透過 /browser：執行 /browser 以驅動本機 Google Chrome（v144+) 透過 Chrome DevTools MCP，在隔離的子代理情境中。
    • DevTools 效能分析與錄製：擷取螢幕截圖、主控台與網路記錄、效能追蹤、Lighthouse 稽核，以及可選擇的 MP4 工作階段錄影。

    深入了解瀏覽器使用方式.

    提及與引用

    標題為「Mentions and quoting」的章節

    將代理指向正確的上下文，讓它不必自行搜尋。

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節

    類型 @ 在訊息框中提及檔案、資料夾、規則與過去的對話，或在回覆、檔案、diff 或產出物中選取文字，然後點選 引用 將它加入您的下一則訊息。

    Antigravity CLI

    「Antigravity CLI」章節

    類型 @ 在提示詞框中提及檔案與目錄，或讓您的提示詞以 @ 以及子代理的名稱，即可傳送訊息給該子代理。

    深入了解提及與引用.

    語音轉錄

    「語音轉錄」章節

    Antigravity 具備內建即時語音轉錄，讓您可以使用自然語音提示代理並留下回饋。

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節
    • 啟動或停止: 按一下訊息框旁的麥克風按鈕開始錄音，再按一下即可停止。您也可以按下 Ctrl + M 開始錄製，再按一次即可停止。
    • 即時檢視: 在您說話時，您的話語會即時轉錄到訊息框中.
    • 對話感知: Antigravity 會將您最近的對話與游標周圍的文字提供給語音辨識器，讓專案專屬術語更有可能正確辨識.
    • 適用位置: 在訊息方塊中使用語音來開始對話並傳送提示詞更新；在產出物評論中，則可對計畫、程式碼差異與交付成果留下精確的行內意見回饋。
    • 與代理交談：若要與代理進行口頭雙向對話而非聽寫，請使用 語音模式.

    Antigravity CLI

    「Antigravity CLI」章節
    • 與代理交談：執行 /voice live 或按下 F6 開始 語音模式，與代理進行口頭雙向對話。
    • 開始聽寫：執行 /voice dictate 或 /record，或按下 F5. 您的話語會出現在提示框中，您可以在傳送前編輯.
    • 透過 SSH 聽寫: 當 CLI 在遠端機器上執行時，請執行 agy mic-serve 在您的本機上，將麥克風串流傳送給它。
    • 可用性: CLI 中的語音聽寫目前不適用於商務或企業版帳戶。

    深入了解 CLI 中的語音聽寫.

    遠端控制

    「遠端控制」章節

    遠端控制可讓您從任何網頁瀏覽器操控與監控跨多台機器的 Antigravity App 工作階段與 Antigravity CLI 執行個體：

    • 從任何裝置工作: 在您的工作站上啟動長時間執行的代理工作，然後透過手機或筆記型電腦監控進度或核准動作。
    • 保留您的本機設定: 代理能完整存取您工作站的檔案、工具鏈、憑證與 Git worktree，無需另設環境.
    • 接收通知：在任務完成或需要您的輸入時，接收瀏覽器推播通知。

    若要開啟遠端控制：

    • Antigravity 應用程式
    • Antigravity CLI

    Antigravity 應用程式

    「Antigravity App」章節

    於 設定, 開啟 應用程式 並開啟 啟用遠端控制. 接著您可以輸入 裝置名稱 識別這台機器。

    Antigravity CLI

    「Antigravity CLI」章節

    • 遠端工作區與資源：建立連結至 GitHub 存放區、Google Drive 檔案和已上傳檔案的遠端專案。
    • 隨時隨地存取：從 Antigravity App、Antigravity CLI 或任何桌機或行動瀏覽器開始並監控遠端對話，網址為 antigravity.google.com.

    自動化

    標題為「Automations」的章節

    自動化（先前稱為排程工作）讓您可以預先規劃專案，依排程傳送訊息給您的代理，即使您不在也一樣。從下列位置開啟它們： 自動化 在左側邊欄中：

    • 可重複：設定基於時間的觸發器以定期啟動對話。
    • 模型層級: 每個自動化都會以您選擇的模型層級執行：Flash Lite、Flash（預設）或 Pro.
    • 大約時間: 執行會在接近排定時間時開始，而非在確切的分鐘。Antigravity 會將它們分散，最多達間隔的 10%，且不超過 15 分鐘。
    • 依需求執行: 立即使用下列方式執行自動化： 立即執行 從其選單中，或選取 使用提示詞建立 讓代理引導您設定新的項目。

    若要在單一對話內設定計時器或定期檢查，無論是在應用程式或 CLI 中，請使用 /schedule 指令.

    標題為「Built-in browser」的章節

    使用內建瀏覽器在側邊欄中檢查您執行中的應用程式或閱讀文件，位置就在您的對話旁邊，並可將代理指向您在頁面上看到的確切內容。

    • 前往某個 URL 或搜尋: 在網址列中輸入。對於不使用 HTTPS 的本機伺服器，請包含 http://，例如 http://localhost:3000.
    • 導覽與擷取：使用 返回, 轉寄, 重新載入, Downloads, 將螢幕截圖加入對話，或 在外部瀏覽器中開啟 在工具列中。按一下網址列中的連線安全性圖示，即可檢查憑證詳細資訊，或刪除該網站的 Cookie 與網站資料（v2.30.0+).
    • 將各個登入分開保持：與代理對話的對話視窗。您可以像其他 Visual Studio 工具視窗一樣，將它停駐在任何位置。 當您重新啟動 Visual Studio 時，Antigravity 會為每個解決方案還原您上次作用中的對話。 設定 > 瀏覽器 (v2.30.0+).

    若要將代理指向頁面的某一部分（v2.30.0+)，選取文字並按右鍵選擇 留言 （或按下 C) 留下錨定意見回饋，或 引用 （或按下 Cmd + L 於 macOS， Ctrl + L 在 Windows 與 Linux 上）將選取的段落與頁面 URL 插入您的訊息方塊。

    版本控制系統 (VCS) 面板

    「版本控制系統（VCS）面板」章節

    • 比較檢視:
      • 未提交：檢視所有已暫存與未暫存的工作樹變更。
      • 分支: 檢閱目前分支上的所有變更。
      • 代理編輯: 檢視代理在對話中修改過的檔案。
    • 檔案動作: 逐一對檔案暫存、取消暫存或捨棄未暫存的變更。

      • 提交: 建立本機提交；如果提交訊息留空，會自動產生.
      • 修訂: 將變更加入最新提交.
      • 推送：將分支提交傳送至遠端儲存庫。
    • 意見回饋: 在 diff 的行上留言，將意見回饋傳送給代理.
