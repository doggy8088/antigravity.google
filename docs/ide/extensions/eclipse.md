# Eclipse

[標題為「Eclipse」的章節](#eclipse)

The **Google Antigravity** 擴充功能，可在下列位置取得：
[Eclipse Marketplace](https://marketplace.eclipse.org/content/google-antigravity)，
將 Antigravity 代理直接帶入 Eclipse。委派複雜的程式設計
任務、執行多步驟代理工作流程，並審查建議的檔案變更
，無須離開您的 Eclipse 工作區。

---

## 先決條件

[「前置條件」章節](#prerequisites)

安裝
擴充功能前，請確保你符合下列先決條件：

- **Eclipse**: [Eclipse](https://www.eclipse.org/downloads/) 2026-06 或更新版本 ，適用於 macOS、Linux 或 Windows.
- **Antigravity 權利**: 具有任何 Antigravity 方案 （包括免費版）的 Google 帳戶，或已啟用下列功能的企業版帳戶： **[Gemini 企業版](/docs/enterprise)**.

---

## 安裝與設定

[「安裝與設定」章節](#installation-and-setup)

完成下列步驟，將 Google Antigravity 擴充功能安裝到
Eclipse：

1. 開啟 Eclipse。
2. 按一下 **說明** 在頂部選單列中，然後選取 **Eclipse Marketplace…** 從下拉式選單中。
3. 搜尋 **Google Antigravity** （發布者為 **Antigravity Eclipse 發行者**).
4. 按一下 **安裝** 並完成安裝精靈。
5. 在出現提示時重新啟動 Eclipse。安裝後首次啟動時， **Antigravity** 檢視會自動在編輯器 區域的右側開啟。請確認您信任這些專案資料夾以繼續。

若要開啟或隱藏 **Antigravity** 檢視，請選取 **Antigravity** >
**切換聊天** 在頂部選單列中（或按下 Cmd + Option + E 於 macOS 或
Ctrl + Alt + K 在 Windows 與 Linux 上）。

---

## 驗證與登入

[「驗證與登入」章節](#authentication-and-sign-in)

首次啟動時，請依照 Antigravity 面板中的登入提示，
在您的瀏覽器中進行驗證：

- **個人帳號**: 使用您的個人 Google 帳戶登入。
- **企業帳戶**: 點擊 **使用 Gemini Enterprise 登入**， 以您的企業身分驗證（包括 BYOID 與 Workforce Identity Federation），然後選取您組織的 **Google Cloud 專案** 和 **區域** 在提示時。

若要稍後切換帳戶、變更驗證方式，或設定 AI 模型與
MCP 伺服器偏好設定，請選取 **Antigravity** > **設定…** 在
頂部選單列中。
