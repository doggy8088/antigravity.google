# 瀏覽器總覽
[「瀏覽器總覽」章節](index.html#browser-overview)
Google Antigravity 可開啟、讀取並操作本機 Chrome 瀏覽器，讓您測試開發中的網站、閱讀文件來源，並自動化各種瀏覽器工作。

---

## 核心機制
[「核心機制」章節](index.html#core-mechanisms)
使用專門的 [瀏覽器子代理](https://antigravity.gh.miniasp.com/docs/subagents)，Antigravity 會視需要操作瀏覽器分頁，擷取螢幕截圖並將動作影片儲存為互動式產出物。

若要完全停用瀏覽器工具，請切換 **瀏覽器工具** 設定，位於 **瀏覽器** 使用者設定區段。

---
