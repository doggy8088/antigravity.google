# 瀏覽器錄製
[「瀏覽器錄影」章節](index.html#browser-recordings)
每當瀏覽器子代理與瀏覽器互動時，都能產生其動作的錄影供您審查。可用時，您可以在瀏覽器步驟 UI 的底部查看此播放。

所有瀏覽器錄影也會儲存為錄影產出物供您審查。此檢視會循環播放瀏覽器子代理的動作。
