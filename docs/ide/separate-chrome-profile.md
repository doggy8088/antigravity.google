# 獨立的 Chrome 設定檔
[「獨立的 Chrome 設定檔」章節](#separate-chrome-profile)
為了將瀏覽器與您的一般瀏覽隔離，它在下列項目中運作 [獨立的 Chrome 設定檔](https://support.google.com/chrome/answer/2364824).

由於 Chrome 設定檔是相互隔離的，此設定檔不會共用您一般瀏覽設定檔中的任何 Cookie 或登入資訊。不過，所有登入狀態都會保留，因此日後每次開啟瀏覽器時，您的帳戶都會保持登入狀態。

若您啟動此設定檔時正常 Chrome 瀏覽器已開啟，它會顯示為獨立的 Dock 圖示，並以獨立應用程式執行。若 Chrome 事先未開啟，此應用程式外觀與預設設定檔相同。若要返回預設設定檔，請結束應用程式並重新啟動 Chrome。
