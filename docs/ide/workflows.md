# 工作流程
[「工作流程」章節](#workflows)
工作流程讓您定義一系列步驟，引導代理完成重複性任務，例如部署服務或回應 PR 留言。這些工作流程會儲存為 Markdown 檔案，讓您能以可重複的方式執行關鍵流程。儲存後，您可以在代理中使用斜線指令呼叫工作流程，格式如下 `/workflow-name`.

規則在提示詞層級為模型提供持久、可重複使用的內容，而工作流程在軌跡層級提供結構化的步驟或提示詞序列，引導模型完成一系列相互關聯的任務或動作。

完成下列步驟以建立工作流程：

1. 開啟 自訂項目 面板，使用 … 選單，位於編輯器的代理面板頂部 。
2. 導覽至 工作流程 面板。
3. 按一下 + 全域 建立可在所有工作區存取的新全域工作流程，或點選 + 工作區 建立專屬於目前工作區的工作流程。

若要執行工作流程，請在代理中使用下列項目呼叫 `/workflow-name` 指令。您也可以在工作流程中呼叫其他工作流程。例如， `/workflow-1` 可包含指令，例如「呼叫 `/workflow-2`」與「呼叫 `/workflow-3`」。呼叫後，代理會依序處理工作流程中定義的每個步驟，執行指定的動作或產生指定的回應。

工作流程會儲存為 Markdown 檔案，包含標題、描述，以及一系列供代理遵循的具體指令步驟。每個工作流程檔案限制為 12,000 個字元。
